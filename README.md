# Dial-Up Debate / Roundtable 98

Windows installers and automatic update releases for the Roundtable 98 desktop.

[Download the latest version](https://github.com/kracklejack/dialup-debate-releases/releases/latest).

The desktop contains Debate Room, AI Chat, Notepad, Debate Archive, Connections, and Software Updates. It connects to official provider CLIs using the user's own account.

This is a **releases-only repository**. Application source, chats, notes, account settings, and credentials are not stored here.

To move from version 0.2.0, install a current setup file once. Later versions can be downloaded and installed from **Start → Software Updates** inside the application. User data stays on the computer.

Windows 10/11 x64. Installers are currently unsigned.
